# Using the preserved site

1. Open [PharmaPath](https://pharmapath.org) in a browser with an internet connection.
2. Browse the preserved project overview.
3. Select a product action to read the retirement notice, then close the notice to return to the overview.

PharmaPath was retired on October 11, 2026. No installation or account is required. Search, medication lookup, sign-in, watchlists, notifications, account settings, and form submissions are unavailable.

Contact pharmacies directly for prescription availability and qualified clinicians or pharmacists for treatment questions.
