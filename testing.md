# Testing PharmaPath

Test only the public experience at [pharmapath.org](https://pharmapath.org). Use fictional, non-sensitive data and a disposable test account when sign-in is required.

## Suggested Journey

1. Open the site on desktop and a narrow mobile viewport.
2. Search for medication context and confirm the copy does not promise live inventory.
3. Try the pharmacy-guidance path with location permission allowed and denied.
4. Test keyboard navigation, visible focus, form errors, loading states, and recovery after a failed request.
5. If using a disposable account, test sign-in, sign-out, password reset, settings, and passkey management without sharing credentials.
6. File a public bug report with the URL, device/browser, expected result, actual result, and reproducible steps.

Never submit prescription numbers, insurance data, health records, pharmacy account details, real credentials, or screenshots containing them. Send security findings privately to [security@pharmapath.org](mailto:security@pharmapath.org).
